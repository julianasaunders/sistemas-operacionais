# 💻 Sistemas Operacionais

Este repositório reúne anotações, atividades e projetos desenvolvidos durante os estudos de **Sistemas Operacionais**, no terceiro ciclo de **Análise e Desenvolvimento de Sistemas**. Os materiais estão organizados por aula e acompanham temas que vão da história da computação à virtualização, à computação em nuvem e ao deploy de aplicações.

## 📚 Conteúdo das aulas

| Aula | Assunto | Material |
|---|---|---|
| **01** | Apresentação da disciplina e conceitos iniciais de sistemas operacionais | [Resumo, mapa mental e linha do tempo](Aula-1/README.md) |
| **02** | Evolução histórica e gerações dos sistemas operacionais | [Estudo histórico](Aula-2/README.md) |
| **03** | Tipos de sistemas operacionais e controle de versão com Git | [Resumo e manual de clone](Aula-3/README.md) |
| **04** | Arquitetura do sistema operacional, kernel e instalação do Windows | [Resumos e atividades](Aula-4/README.md) |
| **05** | Virtualização, Oracle VirtualBox e distribuições Linux | [Manual e comparação](Aula-5/README.md) |
| **06** | Computação em nuvem, containers e deploy no Render | [Resumo e manual](Aula-6/README.md) |
