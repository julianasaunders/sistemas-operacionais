# 🖥️ Aula 02 — Evolução dos Sistemas Operacionais

Como os computadores passaram das válvulas aos dispositivos móveis? Esta aula acompanha a evolução do **hardware** junto às mudanças na forma de executar programas, compartilhar o processador e interagir com as máquinas.

## 🧭 Percurso histórico

| Período abordado | Principais conceitos |
|---|---|
| **1945–1955** | Válvulas eletrônicas, painéis de conexão e programação em código de máquina. |
| **1955–1965** | Transistores, sistemas em lote (*batch*) e cartões perfurados. |
| **1965–1980** | Circuitos integrados, multiprogramação, *spooling* e tempo compartilhado. |
| **1980–presente** | Computadores pessoais, interfaces gráficas e o legado do UNIX. |
| **1990–presente** | Computação móvel, smartphones e gestão energética rigorosa. |
| **Futuro** | Inteligência artificial contextual, nuvem distribuída e segurança automatizada. |

O material também relaciona a trajetória de sistemas como **MULTICS, UNIX, MINIX, Linux, CP/M e MS-DOS** às mudanças de cada geração.
