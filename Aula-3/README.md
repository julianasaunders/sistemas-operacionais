# 🐙 Aula 03 — Tipos de Sistemas Operacionais e Git

Esta aula amplia o conceito de sistema operacional para diferentes plataformas e introduz o **controle de versão** como ferramenta para organizar os estudos e publicar os materiais no GitHub.

## 📂 Materiais disponíveis

| Arquivo | O que apresenta |
|---|---|
| [📝 resumoAula03.md](resumoAula03.md) | Tipos de sistemas operacionais, fundamentos do Git, boas práticas de versionamento e atividades propostas. |
| [🐙 manualClone.md](manualClone.md) | Guia prático para clonar repositórios, commitar e enviar alterações ao GitHub, pelo terminal ou pelo VS Code. |

## 🖥️ Tipos de sistemas operacionais

| Tipo | Foco principal |
|---|---|
| **Mainframes** | Grande porte, alta capacidade de E/S e disponibilidade. |
| **Servidores** | Atendimento a múltiplos usuários em rede, com estabilidade e escalabilidade. |
| **Multiprocessadores** | Múltiplas CPUs/núcleos e escalonamento eficiente. |
| **Computadores pessoais** | Uso individual, interface gráfica e compatibilidade de software. |
| **Portáteis e móveis** | Bateria, sensores, permissões e *sandboxing*. |
| **Embarcados** | Dispositivos dedicados com recursos limitados. |
| **Nós sensores** | Dispositivos minúsculos, orientados a eventos e com comunicação sem fio. |
| **Tempo real** | Prazos rígidos (*hard*) ou apenas degradação de qualidade (*soft*). |
| **Cartões inteligentes** | Ambiente restrito, criptografia e autenticação. |

## 🔄 Fluxo de trabalho com Git

O manual registra o percurso completo de versionamento — `git init`, `git add`, `git commit` e `git push` —, além do clone de um repositório existente e da publicação feita pela interface do VS Code.
