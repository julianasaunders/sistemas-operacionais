## 🖥️ Distribuições comparadas

| Distribuição | Público-alvo |
|---|---|
| **Zorin OS** | Iniciantes e pessoas migrando do Windows ou do macOS. |
| **Kali Linux** | Profissionais de segurança e hackers éticos. |
| **Lubuntu** | Usuários com computadores antigos ou modestos. |
| **Ubuntu** | Desenvolvedores, profissionais e empresas. |
| **Linux Mint** | Usuários comuns e iniciantes. |
| **Fedora** | Desenvolvedores e entusiastas de tecnologias recentes. |

## 🧱 Papéis na virtualização

| Papel | Função |
|---|---|
| **Sistema hospedeiro (*host*)** | Sistema principal instalado diretamente no hardware físico. |
| **Hypervisor** | Camada que cria, gerencia e isola as máquinas virtuais. |
| **Sistema convidado (*guest*)** | Sistema executado dentro da máquina virtual. |
